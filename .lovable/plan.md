# Viorica Lungu Makeup Artist Portfolio

## Goal
Create a cinematic, responsive portfolio that presents Viorica only as an experienced makeup artist, using the supplied beauty and personal photographs.

## What I’ll build
- A full-screen editorial opening with the supplied `Hero-beauty` image, Viorica’s name, makeup artist positioning, and one booking call-to-action.
- A curated portfolio presentation using the supplied editorial makeup photograph, with restrained motion and close-up beauty details.
- An About Viorica section using her supplied portrait and polished copy about her many years of artistic makeup design.
- A clear services section for editorial, bridal, occasion, and creative makeup.
- A simple contact and booking area that works without a paid backend.
- A compact mobile navigation and polished layouts across phone and desktop sizes.

## Quality and discoverability
- Route-specific title, description, Open Graph, and Twitter metadata.
- Semantic page structure, useful image descriptions, keyboard-visible controls, reduced-motion support, and strong contrast.
- Lightweight image loading and a structure suitable for free deployment on Vercel or similar hosting.
- No AI, software development, automation, architecture, or web-development copy in Viorica’s public experience.

## Technical details
- Use the existing TanStack Start application and Tailwind v4 token system.
- Store the four supplied photographs through the project asset service and import their asset pointers.
- Use CSS-led cinematic transitions rather than heavy 3D libraries so the portfolio remains fast and reliable.
- Keep booking as an email-based action until real contact details or a booking service are provided.
